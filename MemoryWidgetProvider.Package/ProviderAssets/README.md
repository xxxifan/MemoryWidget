# ProviderAssets 说明

打包前请放入以下资源文件（名称必须和 `Package.appxmanifest` 一致）：

- `Memory_Icon.png`：小组件选择器图标。
- `Memory_Screenshot.png`：小组件选择器预览图。

建议尺寸：

- `Memory_Icon.png`：64x64 或 128x128。
- `Memory_Screenshot.png`：至少 400x240。

同时请在 `Images` 目录补齐这些基础图标：

- `StoreLogo.png`
- `Square44x44Logo.png`
- `Square150x150Logo.png`
- `Wide310x150Logo.png`
